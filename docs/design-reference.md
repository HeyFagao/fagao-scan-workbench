# 设计参考与本轮实现范围

核查日期：2026-11-09。本文记录产品参考与实现边界，不将第三方网站的功能描述视为本项目已完成的能力。

## 参考对象与源码范围

NovelCatch（网文情报站）用于参考作品发现的信息层级：频道、榜型与分类筛选，封面与书目资料，原始榜位、在读等来源指标，以及查看详情后返回列表的连续体验。其官网将当天排行榜与近期上过榜作品的持续追踪区分，并说明分类与多值题材标签的差别。

相关写作项目原地址为 `mosonlab/open-novel-fanqie`，本次核查原仓库网页和 GitHub API 返回 404。可访问的公开镜像为：

- 仓库：<https://github.com/kongxcer555/open-novel-fanqie>
- 固定提交：`923866bfa203880dd921abff608fa42b4e558406`
- 许可证：MIT；版权行是 `Copyright (c) 2026 novelcatch (https://www.novelcatch.com)`。

该固定版本提供写作 Skill、拆书 JSON 与写作模板、模型调用和字数检查脚本、示例作品；README 规划 12 个 Skill，其中去 AI 味步骤尚未上架，实际有 11 个 `SKILL.md`。README 把 NovelCatch 称为配套网站。文件树没有该网站的采集器、榜单数据库、网页前后端或自动调度源码，因此不能将它描述成已经引入的扫榜框架。

本轮没有复制上述镜像的代码、提示词、示例正文或网站素材；若后续引入其中内容，应固定版本并补充相应许可说明。平台采集继续使用本项目自己的适配器，既有 Oh Story 引用范围和许可见 `THIRD_PARTY_NOTICES.md`。

## 本轮改动映射

| 参考方向 | 本项目落地方式 | 相关实现 |
| --- | --- | --- |
| 用户先看作品，再查看细节 | 纯白色界面中强化作品封面、书名、作者、简介和来源指标；详情、收藏与 WorkBuddy 选书引用保持连贯 | `web/app.js`、`web/styles.css` |
| 频道、榜型和分类可直接切换 | 将常用采集条件放到榜单页，条件在本机保存；条件变化选择对应快照并检查更新 | `web/app.js` |
| 日常浏览不重复手动启动任务 | 在工作台打开且页面可见时检查当前来源，15 分钟内复用新鲜结果；服务端按采集条件合并重复任务并控制失败后的重试 | `web/app.js`、`fagao/server.py` |
| 更新与继续阅读并存 | 保留已有快照和已选作品；有新结果时提示切换；明确查看历史记录时暂停自动更新，可手动恢复 | `web/app.js`、`fagao/store.py` |
| 数据新旧有明确依据 | 区分来源数据日期和本机采集时间；失败保留旧数据，不把重试时间伪装成源榜更新时间 | `fagao/collectors.py`、`fagao/store.py` |
| 数据覆盖范围可解释 | 依来源实际分页，保存原始名次、分页停止原因与缺口警告；元信息缓存减少重复详情请求 | `fagao/collectors.py` |

这里的“自动更新”是本地应用的当前页面更新机制，不代表关闭应用后仍有后台定时服务，也不代表一次打开就遍历所有平台、分类和历史数据。官网的每日更新描述只作为产品参考；未取得其调度实现。

## 暂未实现与数据边界

- 已增加同范围、不同真实来源日期的前次快照比较，展示实际间隔；尚未实现跨 30 天上榜聚合、掉榜后持续追踪、固定日／周／月统计、峰值与趋势曲线。历史快照可以回看，但不等于已有连续可比时间序列。
- 题材标签只展示采集到的来源值；尚未实现题材同义词归并、多标签 AND／OR 筛选，以及独立的字数和连载状态筛选。
- 没有可比历史时不计算或展示推造的涨跌。不同平台、榜型、指标口径不能混成同一热度。
- 封面及其他字段随来源可得性显示；图片失败有本地占位。采集数量上限是请求范围，不承诺来源一定有相应条数。
- 黑岩是需要账号权限的书库，不提供热度排名；番茄短故事仍保留独立未接入状态。实时平台可用性和实测范围以 `docs/platforms.md`、`docs/acceptance.md` 为准。
