## 支持的选项

- 番茄：`channel` 为 `男频` 或 `女频`；`board` 为 `新书榜` 或 `阅读榜`；`category` 由对应频道的真实导航校验。默认 `女频／古言脑洞／新书榜`。
- 起点：`男频／全部`；榜型 `月票榜、畅销榜、签约新书榜、公众新书榜、新人新书榜、推荐榜`。不同榜型不互相改名。
- 刺猬猫：`综合／全部`；已验证 `月票榜`，固定月榜周期（`period=月榜`），支持沿真实下一页链接读取，最多 100 页。其他榜型保留独立的未验证适配，不计入可用验收。
- 黑岩：默认入口固定为用户提供的腾讯文档书单，不向旧掌文后台发送自动采集或登录请求。文档本身的分表、登录和授权由腾讯文档页面处理。

## 黑岩书单与登录

用户指定的来源是腾讯文档书单：

<https://docs.qq.com/sheet/DYVNwaVJZV2ZxTWl3?tab=q1ans7>

工作台提供“打开黑岩书单”外链，保留文档 ID 和 `tab=q1ans7`。链接通过普通浏览器打开，用户在腾讯文档页面登录或申请访问。工作台不复制浏览器资料、不检测普通浏览器 Cookie、不假设外链已登录或内容已导入。此入口不需要 Node、Playwright 或单独下载 Chromium，缺少旧浏览器依赖不影响点击书单。

旧版参考 Oh Story 接入的 `https://manage.zhangwenpindu.cn/books/booklist` 是掌文后台书库，与本次腾讯文档不是同一来源。旧适配器仅为维护兼容保留；不是默认黑岩入口，也不作为此书单的采集成功证据。旧用户数据和浏览器资料不因切换入口而删除。

若用户明确要求单独恢复旧后台采集，维护者先按 INSTALL.md 的可选步骤准备 Node、锁定 Playwright 依赖及 Chromium，验证 worker，再在专用窗口由用户登录具有书库资格的账号。普通读者账号不代表后台权限；只有实际取得书库响应才可报告该旧适配可用。未实测不向普通用户展示成功状态。

## 启动前本地自检

`scripts/launch.py --check` 检查 Python 版本、SQLite 内存读写、HTTPS 组件、必要页面文件和番茄字表。正常启动也先运行同一检查。安装器只在自检和服务身份检查均通过后返回 `ready`；失败由 WorkBuddy 修复运行时或完整程序资源后重试。这个检查不登录平台、不请求榜单，不代表外站网络和账号已通过验收。

## 正文自动取得

`fagao.fanqie_content` 通过正常公开目录与 reader SSR 页读取正文，和榜单共用用户提供的 362 字映射。每个请求核对作品 ID 与章节 ID，控制间隔并缓存目录及章节；需要权限、锁章、验证页、未知字符和身份不符时停止，不使用其他解密服务或自动购买。

实测作品《上朝第一天，吃瓜自爆我女扮男装》当时目录 70 章，取得前 3 章共 9,600 字符，无缺章、无残留 PUA；耗时 39.41 秒。正文未上传公共仓库。这只验证了指定作品与章节，不代表所有作品和全书均可取得。

GUI“目录与正文”支持前 N 章、指定目录起点及明确选择全部已发布章节，完成后保存到固定快照／作品并提供 TXT。下载被取消或后续失败时保留已取得章节，记录缺失原因。`coverage_complete` 表示本次请求范围完成且内容核验通过；`complete` 还要求作品已完结、完整目录全部取得。连载作品全部已发布章节仍不能称全书完结。

v0.5.1 将“目录齐全”与“正文完整”分开核验。逐章保留来源 `chapterWordNumber` 与实际正文非空白字符数，后者不含标题、HTML 和排版空白；只有来源给出精确正整数字数且实际长度不小于来源值，才通过该章核验。单项目录可使用详情 `wordNumber` 回退，多章作品不平均分摊全书字数；全目录还核对全书总数。短于来源值保存为 `partial` 公开片段，缺少可核对字数保存为 `unverified`，两者均不能标记请求范围或全书完整。章数齐全、`needPay=0` 或未上锁都不能替代字数核验。

旧章节缓存缺少核验信息时重新获取。升级时自动将旧公开下载记录、关联任务和报告的完整性标记更正为未确认，保留原正文、记录 ID 和报告正文。工作台卡片、预览、任务消息及 TXT 头统一显示实际范围与核验依据。用户手动导入的完整性仍显示为用户标记。

CLI 兼容 `fetch-text --task ID --chapters 3`，增加 `--start` 与 `--all`。下载后以 `resume` 固定原作品重新关联文本；不能用后来切换的页面对象替换原任务。目录最多 5,000 章、单份正文最多 800 万字符；超限或不足按实际返回，不假称完整下载。

### 起点、刺猬猫公开开篇（v0.7.0-dev.7）

这两个平台统一使用“目录与正文”入口，GUI 只提供前 10 章以内的选择；CLI 可请求前 1—10 章，默认前 3 章。限制同时在页面、任务入口与取文模块执行，拒绝其他起点、超过 10 章及 `--all`。正文读取前重新核验官方目录，只使用原始目录第 1—10 项；锁章、失败和取消均不以第 11 项及以后补足数量。来源目录不足 10 项时以实际数量为准。

`fagao.opening_content` 独立实现官方匿名阅读适配。起点读取官方移动目录与章节 SSR；刺猬猫使用官网向普通访客提供的会话及公开章节响应，随包提供固定版本的纯 Python AES 组件还原正常阅读内容，不需要额外安装运行时。付费章节、登录或验证码要求、异常重定向、作品/章节身份不符会停止；不自动购买、不读取浏览器凭据。

目录和正文分别保留来源与实际范围。正文仍逐章核对来源字数；无精确字数时为 `unverified`，不据章数齐全声称内容完整。即使一本作品只有 10 章，这条取文路径的 `complete` 也固定为 false，明确是开篇资料。目录缓存在当前账号资料目录内，按时间、数量和总大小约束，正文请求不信任缓存来决定章节窗口。

用户提供的 DSH Rank Scan v0.6.4 插件用于核查榜单与元数据设计，原插件没有正文下载实现。本次未整包引入插件、第三方统计接口或其个人资料；第三方许可与来源见 `THIRD_PARTY_NOTICES.md`。真实平台样本验证及本次测试结果见 [验收记录](acceptance.md)，不能据单本样本推断所有作品可读。

## 本地测试

`python3 -m unittest discover -s tests -p test_collectors.py -v` 覆盖数据非代码执行、PUA 不冒充标题、身份交叉验证、原榜名次保留、无文本时失败、付费章节不请求、未登录不会模拟成功和短故事不混入长篇。

2026-11-09：v0.1 的 13 项采集单元测试全部通过；`npm install --package-lock-only --ignore-scripts` 成功从 npm 注册表解析 Playwright `1.62.1` 并生成锁文件。真实番茄样本榜单版本时间为 `2026-11-09T05:10:00+00:00`；采集时刻由主服务另行记录。

本次还修复了番茄 SSR 对缺省字段输出裸 `undefined` 的兼容问题：只将 JSON 字符串之外的该标记标准化成 `null`，不执行源页面代码，保留正文字符串中的同名词。失败详情仅按原版本、原 ID 顺序补读一次；重试仍失败则返回缺口。
