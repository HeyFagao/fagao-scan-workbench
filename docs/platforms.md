## 支持的选项

- 番茄：`channel` 为 `男频` 或 `女频`；`board` 为 `新书榜` 或 `阅读榜`；`category` 由对应频道的真实导航校验。默认 `女频／古言脑洞／新书榜`。
- 起点：`男频／全部`；榜型 `月票榜、畅销榜、签约新书榜、公众新书榜、新人新书榜、推荐榜`。不同榜型不互相改名。
- 刺猬猫：`综合／全部`；已验证 `月票榜`，固定月榜周期（`period=月榜`），支持沿真实下一页链接读取，最多 100 页。其他榜型保留独立的未验证适配，不计入可用验收。
- 黑岩：`channel` 为 `全部、男频、女频`；`category` 和 `board` 都固定 `书库`；默认最多检查 100 页，按实际来源结束停止；需要已授权账号验证。

## 黑岩登录的实际机制

1. 工作台调用 `auth('heiyan', 'login', data_dir)`，启动工程独立的 Playwright 持久浏览器。
2. 资料目录在用户数据目录下的 `browser/heiyan/`，不复制普通 Chrome 资料，也不对外开放 CDP 端口。
3. 用户在 `https://manage.zhangwenpindu.cn/books/booklist` 完成登录。
4. `auth(..., 'check', ...)` 检查同一浏览器的登录状态，再用该会话正常访问书库接口。
5. 只有实际取得 `data.rows` 才返回 `connected`；无 token 返回 `logged_out` 或 `expired`；401 为 `expired`，403 为 `forbidden`；网络错误与字段变化分别显示。
6. 凭据仅存在专用浏览器资料中及 worker 内存中；JSON 回包不含 Cookie、token 或 Authorization。日志不写原始请求错误。

支持界面每次等待检查完成后，再间隔几秒检查；不要用无等待的定时器积压请求。同一数据目录共用一个 worker，Python 端串行锁定调用，防止多个进程争用资料目录。退出本地服务时关闭专用浏览器。

安装浏览器依赖：`npm ci --omit=dev --ignore-scripts`，然后 `npm run browser:install`。首次需网络；私有 Node 的持久配置见 INSTALL.md。普通番茄、起点元信息采集只依赖 Python 标准库，浏览器依赖失败不阻断它们。

## 正文自动取得

`fagao.fanqie_content` 通过正常公开目录与 reader SSR 页读取正文，和榜单共用用户提供的 362 字映射。每个请求核对作品 ID 与章节 ID，控制间隔并缓存目录及章节；需要权限、锁章、验证页、未知字符和身份不符时停止，不使用其他解密服务或自动购买。

实测作品《上朝第一天，吃瓜自爆我女扮男装》当时目录 70 章，取得前 3 章共 9,600 字符，无缺章、无残留 PUA；耗时 39.41 秒。正文未上传公共仓库。这只验证了指定作品与章节，不代表所有作品和全书均可取得。

GUI“目录与正文”支持前 N 章、指定目录起点及明确选择全部已发布章节，完成后保存到固定快照／作品并提供 TXT。下载被取消或后续失败时保留已取得章节，记录缺失原因。`coverage_complete` 表示本次请求范围完成；`complete` 仅在作品已完结且完整目录全部取得时为真。连载作品全部已发布章节仍不能称全书完结。

CLI 兼容 `fetch-text --task ID --chapters 3`，增加 `--start` 与 `--all`。下载后以 `resume` 固定原作品重新关联文本；不能用后来切换的页面对象替换原任务。目录最多 5,000 章、单份正文最多 800 万字符；超限或不足按实际返回，不假称完整下载。
