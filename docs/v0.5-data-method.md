# 数据看板与黑马规则核对

核对日期：2026-11-09。参考材料为用户提供的《番茄榜单工具包-2026-11-09》中的本地复刻应用及站点拆解。本文区分源包实际计算、界面文案与发糕采用的统计口径，不将页面描述当作已有算法。

## 工具包实际包含的计算

源包 `03-复刻应用/refresh.py` 把原始字数除以 10,000，再保留一位小数写入 `word_count`；因此该字段单位为“万字”。在读数量是人数。

| 项目 | 源包代码实际行为 |
| --- | --- |
| 每万字在读 E | 在读人数 ÷ max(字数万字值, 0.1) |
| 黑马加权分 | 0.6 × E + 前次记录以来的在读人数差 ÷ 1,000 |
| 分级 | 分数严格大于 6,000 为 S，大于 3,000 为 A，大于 1,200 为 B，其余为 C |
| 前端默认字数窗口 | 8–15 万字，可切 8–10、10–12、12–15 万字 |
| 前端默认在读下限 | 0；“7 日峰值在读大于 1 万”只有说明文字，没有对应峰值计算 |
| 效率榜排序 | 按每万字在读降序；某些页面说明却写成在读人数降序 |
| 品类汇总 | 书目数量、平均在读或平均每万字在读、历史人数差合计 |

上述加权系数和等级阈值是源包中的启发式规则，材料没有提供收入、付费转化、后续表现等校准或回测证据。它们不能解释成爆款成功率。

## 本版可复算的黑马候选

候选条件为番茄新书榜、原始字数 **80,000–150,000 字（包含两端）**、当前在读 **至少 10,000 人**。8–15 万字沿用参考界面的默认窗口；当前在读下限是本版明确采用的筛选条件，不替代未取得的七日峰值。

效率 `E = 在读人数 × 10,000 ÷ 原始字数`，使用原始字数计算，不先四舍五入为万字。候选按 E 降序展示，候选总数按实际符合条件的去重作品计数，表格展示其中前 10 本。零字数或缺少字数、在读的记录不进入候选。

有同来源、同范围、同作品、不同来源日期的有效在读时，才同时展示参考加权分 `0.6 × E + 在读人数差 ÷ 1,000`。优先使用准确七天前的同源记录，否则使用实际前次日期。计算用未舍入 E，显示保留两位小数，并标明实际日期间隔。零增长与负增长保留；没有历史时该项为空，不以零代替。不同间隔的加权分不参与候选排序，本版不显示 S／A／B／C 等级。

## 接入时纠正的差异

- 原界面传入 `min_w`、`max_w`、`min_r`，后端黑马接口读取的是 `min_words`、`max_words`、`min_reads`，筛选可能没有实际生效；后端也没有采用前端传入的排序参数。
- `growth7` 实际放的是最近一个历史记录以来的在读人数差，前端又给它添加百分号。历史间隔并不固定为七天，人数差也不是增长率。
- 没有历史时，源包将缺失增长转为零；这会把“没有观测”误写成“没有增长”。发糕保留缺失值。
- 原历史文件只按作品 ID 存储名次，会混淆同一本书在不同榜型或分类的位置。发糕的历史比较保留平台、频道、分类、榜型、周期及作品 ID。
- 源包的黑马分析前端期待 `horse_formula`、`top_horses` 等丰富字段，但其本地后端只返回分类聚合列表。不能宣称已经存在一套可直接搬用的“黑马故事共性公式”。
- 原界面还标注“新书榜·未上推荐榜”，但该本地黑马接口没有做推荐榜排除。发糕不把当前筛选候选描述成已经核实未上其他榜单。
- 源包“千字在读”的部分文案与实际“每万字在读”计算不一致。发糕统一使用“每万字在读”，计算用未预先四舍五入的原始字数。

## 看板的共同统计边界

番茄只纳入男频、女频新书榜；阅读榜不进入样本、图表、候选或比较基线。起点与刺猬猫保持独立月票榜面板，月票不改名为在读人数。

每个范围使用最新来源版本；同一版本较短的分页预览不会替换已经保存的完整记录。平台内作品数按作品 ID 去重，分类统计仍保留相应分类样本数。男女频切换需要同时改变图表、指标和候选的分母。

图表使用真实可解析指标，缺失值显示为缺失，不补零。中位数、分位数与分布的有效样本数应可核对；书目量不等于分类规模的全量估计，在读合计不等于去重读者人数。

历史增长仅在同来源、同范围、同作品且有不同来源日期记录时计算，展示实际比较间隔。没有历史时仍可展示当前字数、在读和效率筛选结果，但不能称为已经观测到上涨。

图表中的作品点和候选书目保留 `snapshot_id` 与 `book_id`，打开后沿用既有选书、下载和 WorkBuddy 分析流程。图表取样只用于绘图；总体指标和分布应在完整有效样本上计算。

本轮参考功能和统计思路，自行实现图表与界面；未复制源包中来源许可未明确的整套静态页面。


## 公开历史数据的补充

公开 FanqieRankTracker 快照只纳入男频、女频新书榜，不导入阅读榜或上游 AI 摘要。当前核验每分类最多 20 条，仍是榜单样本，不代表全站规模。原始在读是诸如“9.4万”的展示值，换算后的增量也受原显示精度影响。

公开源提供完整七日前文件且同一作品在两期同分类中出现时，才计算这两期的实际在读变化。未出现的作品不补零，不推断为新书或掉榜。公开源没有字数，因此其记录单独不能计算每万字在读或黑马效率；公共历史变化单独展示，与现有直接采集的效率候选分开。来源、日期、有效比较数量与样本范围都应可查看。
