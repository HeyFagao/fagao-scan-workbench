# 账号与使用说明

本文件对应 **`0.7.0-dev.11` 扫榜体验版**。客户端发行版本和校验值见 ShiQi-Han03/fagao-scan-workbench 默认分支的 `install-release.json`，由安装助手按 [INSTALL.md](../INSTALL.md) 获取并核验。账号资格以官网当前返回为准，不要求普通用户提供生产发布回执。当前实测状态见 [验收记录](acceptance.md)。

## 账号与资格

工作台使用 [发糕写作](https://www.fagaochuangzuo.com/) 的现有账号，会员、付款和续费都以官网为准。免费体验从用户首次在官网扫榜页点击“开始体验”起算，每个账号可领取一次 7 天，老账号也可领取。已有有效字数包购买记录的老账号首次启用领取一次 15 天；之后每次有效购买字数包再续 15 天，未到期时顺延字数包扫榜期限，到期后重新起算。会员继续使用官网真实会员有效期；同时有多种有效权益时，使用较晚的截止时间，不将试用天数写成会员期限。

领取与续期由官网按账号和有效订单记录；换电脑、刷新、重装不会重置，当前字数余额和没有实际付款的赠送/测试码不作为字数包购买凭据。客户端不会在访问页面或连接账号时自动领取。

**本轮实验阶段**，白银、黄金、钻石、至尊四档当前有效会员均可使用，包括付费、赠送和测试权益。

管理员指定的实验账号另有独立工作台使用资格，持续到管理员手动关闭；即使真实会员截止为空或已经过去，也不把它改成未来日期，更不创建付款记录或永久会员。用户页面只显示连接状态和实际需要处理的信息，不展示实验类型或管理员关闭规则；后台保留真实授权类型、期限和停用控制。

官网服务仍保留默认的有效付费会员模式；实验开放范围由服务端显式配置，本地工作台没有切换实验模式或自行开通资格的入口。实验关闭后按官网当时返回的规则使用，不把实验资格作为永久承诺。

每个账号最多绑定 **3 台电脑**。达到上限时，在官网 [工作台电脑管理](https://www.fagaochuangzuo.com/workbench/devices) 移除不再使用的电脑，再连接新电脑。官网基础授权已上线；本轮实验资格以官网实际返回为准。移除授权不删除旧电脑里的本地资料。

| 当前状态 | 可以做什么 |
| --- | --- |
| 官网免费体验、字数包扫榜权益有效，或实验开启时四档会员当前有效（含付费、赠送、测试） | 查看、更新榜单，收藏、导入、取文、翻译上下文、新建分析任务及保存报告 |
| 管理员指定的独立工作台实验账号 | 关闭前可进行上述操作；真实会员记录保持不变 |
| 所有扫榜使用权益到期，已核验本账号历史身份 | 查看、检索和导出本账号已保存的榜单、正文与报告；不能更新、修改或开始新任务 |
| 未登录、当前电脑已移除、账号封禁、工作台停用或无法核验身份 | 暂停打开账号资料；本地资料仍保留，指定实验账号也无例外 |
| 当前权益关联的全额退款，或任何未决的权益退款审核 | 官网暂停许可，实验资格也不能绕过；原资料保留，按官网核验结果恢复 |

部分退款且无待核记录时，跟随官网原有权益。指定独立实验账号没有当前会员权益时，已经完结的历史退款不会永久否定管理员新授予的实验许可。续费或管理员调整实验资格后，点击工作台账号旁的刷新按钮重新确认状态，无须重新安装。

## 第一次连接

1. 首次体验先在 [官网扫榜页](https://www.fagaochuangzuo.com/?module=rankings) 点击“开始体验”。已有当前使用资格的账号无需重复领取。按页面的一段话让 WorkBuddy 安装或更新后，点击本机工作台的“连接发糕账号”。
2. 在正常浏览器中的发糕官网完成登录，核对账号并确认授权。工作台不索取密码、验证码或浏览器 Cookie。
3. 官网将结果返回这台电脑的本地工作台。点击取消会返回工作台，不修改资料；之后可以重新连接。
4. 如果这台电脑有旧版匿名资料，先完成下面的认领或跳过选择，再开始自动读取榜单。

本地页面、采集和 WorkBuddy 命令使用同一账号资格。退出或换号后，页面清除前账号显示内容，任务不会转入新账号；原账号资料仍在本机。

## 旧版资料认领

旧版没有账号隔离，升级时不能凭“第一个登录的人”判断资料属于谁。工作台会先显示旧资料数量和当前账号，暂不自动采集。

- **认领并保留原件：** 由用户勾选确认资料属于当前账号，再复制到该账号空库。程序先建立一致性备份并校验，原数据库、正文与报告保留；不复制旧浏览器会话或授权凭据。
- **跳过，开始使用：** 原资料留在原处，当前账号使用独立资料。选择只对当前账号生效，不把旧资料自动分配给别人。

跳过后，只有当前账号库仍为空时才能再明确认领；已经产生新资料时拒绝覆盖或自动合并。中断的认领需恢复完成，不能通过跳过破坏恢复条件。已经成功认领的资料不会再分配给另一个账号。其他到期账号可以查看已有历史；认领和跳过需要官网返回当前使用资格，有效体验、字数包、会员或仍开启的独立实验资格均可。旧库损坏或不兼容时可以明确跳过并保留原文件；认领需先修复。

维护者可以通过以下命令执行同一流程。`DATA_DIR` 必须替换为该工作台的实际资料目录，解释器使用安装时记录的绝对路径；不要默认换成一份空目录：

```text
PYTHON_ABSOLUTE_PATH -m fagao --data-dir DATA_DIR legacy inspect
PYTHON_ABSOLUTE_PATH -m fagao --data-dir DATA_DIR legacy claim --confirm
PYTHON_ABSOLUTE_PATH -m fagao --data-dir DATA_DIR legacy skip --confirm
```

`inspect` 仅返回数量和归属状态，不输出旧正文。`--confirm` 表示用户已经明确确认相应选择；助手不能把一次普通登录当成认领授权。

## 断网与许可期限

所有账号的新任务许可最长缓存 **15 分钟**。许可同时不超过官网返回的扫榜使用截止时间；会员授权也不超过真实会员截止时间；指定独立实验账号每次同样只取得短时许可，管理员手动关闭后不再续领。实验账号不因“持续到关闭”而取得长期离线许可。官网封禁、工作台停用、移除电脑或退款阻断后，新许可会被拒绝；已经发出的许可最多使用到自己的截止时间，不能承诺离线瞬间撤销。

工作台会提前刷新许可。无法续领时停止后续外部请求，保留已经取得的部分榜单或章节，并说明中断原因。到期后的历史读取也需核验账号身份；身份许可失效且无法联网时，资料保持保存，暂不打开。程序重启后重新联网确认，不把磁盘里的旧状态直接当成有效许可。

## 资料与分发边界

数据保存在用户资料目录中，按账号放入 `accounts/账号摘要/`；授权文件在 `.membership/`。一致性认领备份在 `legacy-claims/`，认领与跳过记录分别为 `legacy-claim.json`、`legacy-decisions.json`。退出、到期与代码升级不会主动删除这些资料。

公共源码、安装包和诊断材料不得带入授权文件、账号资料、认领备份、浏览器会话或本机网络配置。完整个人备份可能包含敏感数据，应由用户自行妥善保存。

本版实现的是官方客户端使用资格控制。历史公开版本与修改过的客户端仍可能独立运行；目前没有把付费核心能力迁到服务器，不能宣称无法绕过。工作台本地服务始终只监听本机 loopback，不开放到局域网或公网。

## 维护者接口约定

官网只向客户端签发工作台专用凭据，该凭据不用于官网付款、兑换、账户登录或其他产品。用户授权页面为 `/workbench/authorize`；浏览器确认使用一次性授权码与 PKCE，回调仅允许本机 `/auth/callback`。源码中不配置生产账号或示例可用令牌。免费体验以 `access_basis=free_trial`、字数包以 `access_basis=word_pack` 标识，`access_expires_at` 是当前扫榜使用截止，`history_access_expires_at` 是可核验的历史权益截止。两种体验必须有官网返回的有限截止，不能从本机时间或会员字段推导。`membership_expires_at` 与 `history_membership_expires_at` 始终保留真实会员含义，旧会员响应兼容。独立实验授权以 `access_basis=experimental_account` 标识，真实会员截止字段保留官网原值；客户端不能靠改本机配置、会员截止或凭据文件取得实验资格。

| 接口 | 用途 |
| --- | --- |
| 官网 `/api/workbench/token` | 单次授权码换取当前电脑的专用凭据 |
| 官网 `/api/workbench/permit` | 按官网当前体验、字数包、会员或实验资格与设备状态刷新短时许可 |
| 官网 `/api/workbench/revoke` | 撤销工作台凭据 |
| 本机 `/api/membership/status` | 获取当前账号使用状态 |
| 本机 `/api/legacy-data/status` | 取得旧资料数量与待选择状态 |
| 本机 `/api/legacy-data/claim`、`/api/legacy-data/skip` | 接收用户明确确认的资料选择 |

访问受保护的本机数据需携带当前状态返回的 `X-Fagao-Account` 和 `X-Fagao-Generation`，阻止旧窗口在换号后读写新账号。认领及跳过使用 POST，另带 `X-Fagao-Request: 1` 与 `Content-Type: application/json`，JSON 为 `{"confirmed":true}`，并要求官网确认的当前使用资格。不要把状态端点、健康检查通过或历史读取许可当作新任务授权。

## 客户端安装

普通用户复制 README 中的一句话即可。执行安装的助手按 [INSTALL.md](../INSTALL.md) 读取公开 `install-release.json`，核验固定提交和安装器 SHA-256，再使用 `--repo` 与 `--commit` 安装。无需用户手动下载 ZIP，不索取私有生产回执，不重新部署官网。已有安装复用原资料目录和固定入口。

## 维护者的隔离预演与官网开放检查

以下仅用于维护者发布或调整服务的验证，不是普通安装的前置材料要求。维护者使用可信本地源码预演时，先核验来源、文件清单和版本；检查归档不含链接、路径穿越、运行数据或凭据，再解压到独立目录。使用已确认的 Python 3.10+ 和同包安装器。隔离预演命令为：

```text
PYTHON_ABSOLUTE_PATH scripts/bootstrap.py --source-dir ABSOLUTE_CANDIDATE_SOURCE --install-root ISOLATED_TEST_INSTALL --data-dir ISOLATED_TEST_DATA --port UNUSED_LOOPBACK_PORT --no-browser
```

所有大写项是待替换参数。源目录、测试资料目录和安装目录不能互相覆盖。这个命令验证安装与本地服务，仍需单独验证授权与页面；本地测试夹具不能用于普通用户安装，不提供绕过授权参数。实际用户安装时复用其既有资料目录和固定入口，不用新的空目录冒充资料保留；普通安装移除 `--no-browser` 并核对真实页面。

维护者发布或调整官网实验规则时的检查顺序：

1. 核对同版生产发布回执中的官网实验配置、页面及回读结果，不能用旧版健康检查代替本版实验规则生效验证。
2. 验证免费首次领取与重复领取、历史字数包首次领取、新购买顺延与过期恢复、退款、会员与其他权益重叠及全部到期只读。验证四档当前有效的付费、赠送、测试权益可用；指定实验账号的独立资格与管理员关闭行为正确，真实会员记录没有被改写。其他到期账号保持历史只读。
3. 保留三台设备、15 分钟许可、退款、封禁、工作台停用、撤销、换号和旧资料归属保护；在目标系统和 WorkBuddy 客户端记录实际安装及任务调用结果。
4. 发布经过检查的客户端提交或交付同版本可信 ZIP，记录真实来源、校验值、安装结果和尚未验证的环境，再发对应安装话术。

主站私有代码、实验账号配置、付款配置和发布脚本单独交付，不进入本客户端公共仓库。安装脚本不顺带修改主站。
