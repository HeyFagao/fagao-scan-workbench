# 会员使用说明

本文件对应 **`0.7.0-dev.1` 开发候选**。候选尚未公开发布，配套官网授权尚未在生产启用。本轮公开源码基线为 `0.6.2`；旧版下载成功不等于完成会员版安装。当前实测状态见 [验收记录](acceptance.md)。

## 账号与资格

工作台使用 [发糕写作](https://www.fagaochuangzuo.com/) 的现有账号，会员、付款和续费都以官网为准。白银、黄金、钻石、至尊四档有效付费会员均可使用。只有赠送或测试权益不算付费资格；官网显示会员等级本身不足以替代付费资格核验。

每个账号最多绑定 **3 台电脑**。达到上限时，在官网 [工作台电脑管理](https://www.fagaochuangzuo.com/workbench/devices) 移除不再使用的电脑，再连接新电脑。该页面随配套官网版本启用，当前候选阶段不保证生产入口已可用。移除授权不删除旧电脑里的本地资料。

| 当前状态 | 可以做什么 |
| --- | --- |
| 有效付费会员，当前电脑授权正常 | 查看、更新榜单，收藏、导入、取文、翻译上下文、新建分析任务及保存报告 |
| 付费会员到期，已核验本账号历史身份 | 查看、检索和导出本账号已保存的榜单、正文与报告；不能更新、修改或开始新任务 |
| 曾经付费，当前只有不计付费资格的权益 | 官网确认既往付费记录后可读取历史；当前赠送期不延长新任务权限 |
| 未登录、当前电脑已移除、账号停用或无法核验身份 | 暂停打开账号资料；本地资料仍保留 |
| 全额退款或权益退款待核 | 官网暂停许可；原资料保留，按官网核验后的结果恢复 |

部分退款且无待核记录时，跟随官网原有权益。续费后点击工作台账号旁的刷新按钮重新确认状态，无须重新安装。

## 第一次连接

1. 启动本机工作台，点击“连接发糕账号”。
2. 在正常浏览器中的发糕官网完成登录，核对账号并确认授权。工作台不索取密码、验证码或浏览器 Cookie。
3. 官网将结果返回这台电脑的本地工作台。点击取消会返回工作台，不修改资料；之后可以重新连接。
4. 如果这台电脑有旧版匿名资料，先完成下面的认领或跳过选择，再开始自动读取榜单。

本地页面、采集和 WorkBuddy 命令使用同一账号资格。退出或换号后，页面清除前账号显示内容，任务不会转入新账号；原账号资料仍在本机。

## 旧版资料认领

旧版没有账号隔离，升级时不能凭“第一个登录的人”判断资料属于谁。工作台会先显示旧资料数量和当前账号，暂不自动采集。

- **认领并保留原件：** 由用户勾选确认资料属于当前账号，再复制到该账号空库。程序先建立一致性备份并校验，原数据库、正文与报告保留；不复制旧浏览器会话或授权凭据。
- **跳过，开始使用：** 原资料留在原处，当前账号使用独立资料。选择只对当前账号生效，不把旧资料自动分配给别人。

跳过后，只有当前账号库仍为空时才能再明确认领；已经产生新资料时拒绝覆盖或自动合并。中断的认领需恢复完成，不能通过跳过破坏恢复条件。已经成功认领的资料不会再分配给另一个账号。到期账号可以查看已有历史，认领和跳过需要续费恢复有效资格。

维护者可以通过以下命令执行同一流程。`DATA_DIR` 必须替换为该工作台的实际资料目录，解释器使用安装时记录的绝对路径；不要默认换成一份空目录：

```text
PYTHON_ABSOLUTE_PATH -m fagao --data-dir DATA_DIR legacy inspect
PYTHON_ABSOLUTE_PATH -m fagao --data-dir DATA_DIR legacy claim --confirm
PYTHON_ABSOLUTE_PATH -m fagao --data-dir DATA_DIR legacy skip --confirm
```

`inspect` 仅返回数量和归属状态，不输出旧正文。`--confirm` 表示用户已经明确确认相应选择；助手不能把一次普通登录当成认领授权。

## 断网与许可期限

新任务许可最长缓存 **15 分钟**，也不会超过官网会员截止时间。官网停用、移除电脑或退款后，新许可会被拒绝；已经发出的许可最多使用到自己的截止时间，不能承诺离线瞬间撤销。

工作台会提前刷新许可。无法续领时停止后续外部请求，保留已经取得的部分榜单或章节，并说明中断原因。到期后的历史读取也需核验账号身份；身份许可失效且无法联网时，资料保持保存，暂不打开。程序重启后重新联网确认，不把磁盘里的旧状态直接当成有效许可。

## 资料与分发边界

数据保存在用户资料目录中，按账号放入 `accounts/账号摘要/`；授权文件在 `.membership/`。一致性认领备份在 `legacy-claims/`，认领与跳过记录分别为 `legacy-claim.json`、`legacy-decisions.json`。退出、到期与代码升级不会主动删除这些资料。

公共源码、安装包和诊断材料不得带入授权文件、账号资料、认领备份、浏览器会话或本机网络配置。完整个人备份可能包含敏感数据，应由用户自行妥善保存。

本版实现的是官方客户端会员控制。历史公开版本与修改过的客户端仍可能独立运行；目前没有把付费核心能力迁到服务器，不能宣称无法绕过。工作台本地服务始终只监听本机 loopback，不开放到局域网或公网。

## 维护者接口约定

官网只向客户端签发工作台专用凭据，该凭据不用于官网付款、兑换、账户登录或其他产品。用户授权页面为 `/workbench/authorize`；浏览器确认使用一次性授权码与 PKCE，回调仅允许本机 `/auth/callback`。源码中不配置生产账号或示例可用令牌。

| 接口 | 用途 |
| --- | --- |
| 官网 `/api/workbench/token` | 单次授权码换取当前电脑的专用凭据 |
| 官网 `/api/workbench/permit` | 按官网付费资格与设备状态刷新短时许可 |
| 官网 `/api/workbench/revoke` | 撤销工作台凭据 |
| 本机 `/api/membership/status` | 获取当前会员状态 |
| 本机 `/api/legacy-data/status` | 取得旧资料数量与待选择状态 |
| 本机 `/api/legacy-data/claim`、`/api/legacy-data/skip` | 接收用户明确确认的资料选择 |

访问受保护的本机数据需携带当前状态返回的 `X-Fagao-Account` 和 `X-Fagao-Generation`，阻止旧窗口在换号后读写新账号。认领及跳过使用 POST，另带 `X-Fagao-Request: 1` 与 `Content-Type: application/json`，JSON 为 `{"confirmed":true}`，并要求有效会员。不要把状态端点、健康检查通过或历史读取许可当作新任务授权。

## 候选安装与正式开放顺序

当前只允许以可信本地候选源码进行隔离验收，不能把未发布候选写成公共安装链接。维护者先用已确认的 Python 3.10+，选择独立的测试资料目录和端口：

```text
PYTHON_ABSOLUTE_PATH scripts/bootstrap.py --source-dir ABSOLUTE_CANDIDATE_SOURCE --install-root ISOLATED_TEST_INSTALL --data-dir ISOLATED_TEST_DATA --port UNUSED_LOOPBACK_PORT --no-browser
```

所有大写项是待替换参数。源目录、测试资料目录和安装目录不能互相覆盖。这个命令验证安装与本地服务，仍需单独验证授权与页面；本地测试夹具不能用于普通用户安装，不提供绕过授权参数。

正式开放时按以下顺序完成：

1. 配套官网增量变更和回滚方案获准后，由主站部署流程发布，先保持功能关闭。
2. 为指定灰度账号开启，实际验证登录、取消、三台限制、到期历史、续费、退款、移除、换号和旧资料认领。
3. 在 Windows、macOS 和 WorkBuddy 客户端记录固定版本安装、浏览器显示及任务调用的真实结果。
4. 发布经过检查的公共客户端正式提交及对应版本说明，核对匿名下载和新目录安装，再启用 README 的正式安装话术。

主站私有代码、付款配置和发布脚本单独交付，不进入本客户端公共仓库。部署审批只针对具体可审查的候选，不由安装脚本顺带执行。
