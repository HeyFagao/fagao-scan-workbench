# 本地小说投稿

从工作台顶部打开**小说投稿**。填写作品名、笔名、邮件主题及投稿信后，点**保存草稿**。草稿保存在本机；关闭再打开仍能继续编辑。

准备寄出时点**带入投稿助手**。本机窗口会带入这四项文字。第一次使用可在**账号设置**添加自己的 QQ 发件邮箱；再从**编辑名单**启用要联系的编辑，选择本次收件人和附件。先给自己发一封自检邮件，核对主题、正文和附件，再确认正式投递。打开一份草稿不会选中收件人或发出邮件。可用**邮件模板**复用投稿信，通过**投稿记录**看投递进度，主动开启**回信与过稿**后查看回信。邮箱服务接受投递不代表编辑已经过稿。

**数据在哪里**：草稿和独立个人投稿窗口的队列、模板、回信留在本机，不上传发糕的网站。无需工作室账号或扫榜会员。真正收发信时，由自己的设备连接 QQ 邮箱。整合版使用独立资料目录，不自动导入旧版的邮箱授权、已保存稿件或联系人状态。同一系统登录用户可访问其本地投稿资料；不同人共用电脑时可使用各自的系统账号。

**本地维护**：Mac ARM64 和 Windows x64 私有试用包内附已核验的桌面组件和启动入口，解压后使用对应入口即可。仅运行源码时，可用 Python 3.10+ 启动 `scripts/launch.py --submissions`；原生组件从本地受信任的个人版发行物安装，见 `scripts/install_submission_component.py --help`。没有原生组件也能处理草稿。不要使用工作室版安装器或旧版程序代替本地组件。

投稿窗口复用旧个人版的邮箱、联系人、附件、自检、队列和回信代码。工作室的员工账号、集中审核、云端统计和计费没有引入。个人项目的编辑名录没有添加至扫榜公共源码。
