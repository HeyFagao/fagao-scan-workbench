# 发糕扫榜工作台

在自己的电脑上浏览小说榜单、收藏作品、获取可用正文，再交给 WorkBuddy 分析。支持国内榜单和海外网文，资料保存在本机。

## 开始使用

把下面这段话复制到 WorkBuddy：

> 请帮我安装或更新「发糕扫榜工作台」：https://github.com/ShiQi-Han03/fagao-scan-workbench 。按项目说明使用最新已发布版本，保留已有资料和设置，自动完成安装、启动和打开页面。遇到问题先自行诊断、修复并重试，不把排查命令交给我，不反复询问是否继续；确认安装命令结束后仍能打开，再告知完成。只有本人登录、验证码、授权、资料归属或系统必须由我批准时，才提醒我并让我自己操作；不要绕过安全校验。最后简短告诉我结果和下一步。

WorkBuddy 会完成下载、环境准备、安装和打开。你不需要手动下载压缩包或执行命令；页面打开后，点击“连接发糕账号”，在官网完成登录并确认连接。如果发现旧资料，由你选择认领或保留。

以后在同一个 WorkBuddy 项目里说“打开发糕工作台”，即可复用固定入口；选中作品后可以说“分析刚选的这本”或“翻译这本”。关闭网页或对话不会删除记录，电脑重启后仍可通过固定入口打开。

工作台使用现有 [发糕官网](https://www.fagaochuangzuo.com/) 账号。首次在官网扫榜页点击“开始体验”可领取 7 天；有效购买字数包附带 15 天，会员跟随官网有效期。已有字数包购买记录的老账号首次启用也可领取一次 15 天。实际可用权益以官网登录后的状态为准。每个账号最多绑定 3 台电脑，普通到期账号可查看本账号已保存的历史资料。详见 [会员使用说明](docs/membership.md)。

## 日常操作

顶部“外观”可选择浅色、护眼、深色或跟随系统，选择会保存在当前浏览器。外观切换也可在未登录或到期页面使用，不影响收藏、资料和账号资格。

服务与采集已自动隔离 WorkBuddy/IDE 的临时会话代理。需要固定代理或排查断连时，由维护助手按 [网络维护](docs/network.md) 操作。

- 官网确认具有当前使用资格的账号完成授权及旧资料选择后，打开工作台即显示本账号已有榜单，当前条件过期后自动更新；切换平台或榜型也会自动读取。可随时手动更新；失败保留原来的结果。
- 默认最多读取 100 页，遇到来源结束、重复页或访问限制时提前停止，显示实际数量和停止原因。不会把 100 页上限当作已经取得 100 页。
- 作品列表展示来源封面、简介和实际指标；封面失效时显示书名占位。已选作品与历史记录不会因后台更新而悄悄换书，新数据准备好会提示查看。
- 首页后台同步 FanqieRankTracker 公开新书榜快照及可用的七日前记录，先补齐分类样本，再由直接采集持续补充。明确显示来源、真实日期与每分类样本范围，不将公开 Top 样本冒充全榜。公开源不可达时保留已有结果并继续直采，见 [公开数据来源](docs/public-data-sources.md)。
- 首页用数值和图表展示三家平台，保留各自榜型和指标；番茄可以切换全部、男频、女频，只包含新书榜。阅读榜仍可单独浏览，不进入汇总。
- 黑马筛选使用字数、当前在读和每万字在读；有同范围、不同来源日期的历史时，才计算实际增量和工具包的加权指数。筛选窗口、单位与公式可展开查看。书名句式仅作为次要分布统计，不再占据首页的大块公式卡。来源没有指标时不画零值图，具体口径见 `docs/v0.5-data-method.md`。
- 黑岩故事会入口打开用户指定的腾讯文档书单。在腾讯文档页面完成登录和访问授权；工作台不要求后台账号，也不接管文档登录状态。
- 想研究哪本书，先点作品旁的“收藏”，再回到 WorkBuddy 说“分析我收藏的《书名》”。收藏后继续浏览其他书，不会改变收藏的分析对象；收藏只保存书目，正文要另外取得。
- 番茄作品可打开“目录与正文”，下载前几章、指定范围或明确选择全部已发布章节，再导出 TXT。正文自动关联原作品，回到 WorkBuddy 即可继续分析。
- 起点、刺猬猫也可打开“目录与正文”，仅取得原始目录前 10 章以内的公开内容。遇到付费、登录或验证要求就停止，保留已取得章节，不会用后续章节补足数量。
- “榜单观察”展示当前样本的标题关键词、句式、每万字在读和可比较的历史变化；没有历史时不显示虚构涨跌。这是规则统计，实际拆书仍由 WorkBuddy 阅读正文后执行。
- 文本导入只表示已取得用户提供的内容。是否完整、实际章节范围和来源都需要如实登记。
- 页面中的报告由对话分析后保存；本地服务没有偷偷接模型，也不会用固定模板冒充 AI 拆书。

平台实测边界见 [平台能力表](docs/platforms.md)，本次验证记录见 [验收记录](docs/acceptance.md)。首次未授权时显示连接账号入口；具有当前使用资格的账号完成旧资料选择且没有真实数据时，显示实际读取进度，不加载虚构书目。导入文件的准确格式见 [书目格式](docs/data-format.md)。产品设计参考与暂未实现的功能见 [设计依据](docs/design-reference.md)。

本版已融合用户提供的番茄工具包：直接解读榜单字段、公开章节读取、分类批量采集与本机跨榜检索。具体范围和真实验证见 [工具包融合记录](docs/toolkit-integration.md)。全分类采集与跨榜检索可由 WorkBuddy 调用，不要求用户自己操作命令行。

## 海外网文

具有当前使用资格的账号点击侧栏“海外网文”可展开海外平台，首次读取首批作品，向下浏览再取得后续页面；已有数据立即显示，并在后台检查更新。未持有独立实验资格的到期账号仅浏览已保存内容。分类、榜型与指标名称为中文，作品书名、作者及简介保留来源英文。

| 平台 | 当前入口 | 默认条件 |
| --- | --- | --- |
| GoodNovel | 长篇分类榜 | 狼人，可切换言情、总裁等分类 |
| GoodNovel 短篇 | 热门短篇书库 | 全部，可切换言情等分类 |
| Dreame | 新书、上升、月票、畅销、完结、必读榜 | 新书榜 |
| MegaNovel | 长篇分类榜 | 奇幻，可切换都市、科幻、系统与游戏等 |
| Webnovel | 新书能量榜 | 男频，可切换女频；发表不超过 30 天的签约原创作品，周榜 |
| Royal Road | 新星榜 | 官网列表；读取失败时自动使用 RST 公开快照并标注来源日期 |
| Scribble Hub | 周收藏榜 | 官网读取；遇到访问拒绝时可打开官网或导入浏览器保存的榜单 HTML |

Royal Road 官网请求被拒绝或连接失败时，自动改用 RST 已保存的公开新星榜，显示实际快照时间、封面、英文书名、关注及浏览指标；RST 榜单接口未提供作者和简介。Scribble Hub 返回访问拒绝时暂停自动重试，保留已载入书目，并提供官网入口与“导入已打开的榜单”按钮；导入浏览器保存的周收藏榜 HTML 后即可选书。

选中一本后，直接回 WorkBuddy 说“翻译这本”，也可以点击“复制翻译请求”粘贴到对话。复制内容带固定快照与作品 ID，翻译由当前对话完成。原文和收藏照常保存在工作台。开发接口及实际覆盖见 [海外接入说明](docs/overseas.md)。

## 更新已有工作台

安装和升级使用[“开始使用”中的同一段话](#开始使用)，复制给 WorkBuddy 即可。

WorkBuddy 会复用原资料目录和固定入口，完成版本核对后再打开；不要手动覆盖现有程序目录。

## 维护者启动方式

在本工程目录运行：

```sh
python3 scripts/launch.py
```

不自动打开浏览器（便于测试）：

```sh
python3 scripts/launch.py --no-browser --port 18376
```

前台运行并查看日志：

```sh
python3 -m fagao.server --port 18376
```

只绑定 `127.0.0.1`。默认端口为 `18376`；端口属于其他程序或另一份资料目录时，启动器会明确报错，不会打开错误程序。

## 资料位置、更新与备份

默认资料位置：

| 系统 | 默认目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\FagaoWorkbench` |
| macOS / Linux | `~/.fagao-workbench` |
| 自定义 | 环境变量 `FAGAO_DATA_DIR` 或启动器参数 `--data-dir` |

安装器将程序放在资料目录的 `app/releases/版本号`，通过 `app/current.json` 选择版本；数据库、正文与登录状态不放进版本目录。固定启动入口和 WorkBuddy 项目目录不随版本地址变化。更新请遵循 INSTALL.md，不手动覆盖正在运行的版本。会员版把资料保存在 `accounts/账号摘要/`，授权状态保存在 `.membership/`；旧匿名资料留在原处，明确认领时先备份再复制，详情见会员说明。备份前停止自己运行的本地服务；完整私有备份应妥善保管，授权凭据、个人账号数据和浏览器会话不得上传公共仓库或共享压缩包。

启动日志在资料目录的 `logs/workbench.log`。启动后 `server.pid` 记录最近一次新启动进程的 PID；停止前核对进程身份，不能凭可能过期的 PID 盲目结束程序。

积分站正式取得域名后，由维护助手用 `python3 -m fagao config --points-site "实际的 HTTPS 地址"` 配置；网址为空时入口保持禁用。不要填临时假域名。

## 项目来源与验证

当前发行仓库为 [ShiQi-Han03/fagao-scan-workbench](https://github.com/ShiQi-Han03/fagao-scan-workbench)，原始来源为 [hanyyyou/fagao-scan-workbench](https://github.com/hanyyyou/fagao-scan-workbench)。安装助手按 [INSTALL.md](INSTALL.md) 读取默认分支的 `install-release.json`，固定已发布版本后安装；公开仓库下载不要求 GitHub 登录。

Windows 与 macOS 启动入口已提供，Python 缺失时由 WorkBuddy 按 INSTALL.md 准备私有运行时。核心功能使用 Python 标准库与随包提供的纯 Python 组件，无需额外安装依赖；黑岩书单在系统浏览器中打开，不依赖 Node 或 Playwright。历史掌文后台适配仅为维护者保留，默认不作为黑岩入口。平台网络访问、腾讯文档账号权限和正文取得有各自的验证状态，详见平台能力表。GitHub 分发成功、工作台打开、平台数据可用与 WorkBuddy 实际拆书分别验收。
