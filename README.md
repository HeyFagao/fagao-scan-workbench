# 发糕扫榜工作台

一套在自己电脑运行的小说选题工作台。首页以分类对比、字数分布、热度分布、散点图和黑马数据表呈现榜单；番茄汇总只纳入男频、女频新书榜及各自分类，起点、刺猬猫独立统计。纯白界面、真实封面；侧栏“海外网文”汇集 GoodNovel、Dreame、MegaNovel、Webnovel、Royal Road、Scribble Hub 和 GoodNovel 短篇，中文导航、英文书名与简介。需要拆书时，回到 WorkBuddy 说“分析刚选的这本”。

源码仓库：[hanyyyou/fagao-scan-workbench](https://github.com/hanyyyou/fagao-scan-workbench)。

主站入口：[发糕写作](https://www.fagaochuangzuo.com/)。积分站保留导航位置，尚未配置域名。这个工程不会修改主站。

## 开始使用

**把下面这一整段复制到 WorkBuddy 对话框即可发起安装。** 仓库地址已经包含在内，无需另找链接，也无需先下载压缩包、安装 Git 或手动运行终端命令。

> 请帮我安装并打开发糕扫榜工作台，源码仓库是 https://github.com/hanyyyou/fagao-scan-workbench 。先读取仓库的 INSTALL.md、AGENTS.md 和 README.md，按安装说明自动检查本机环境、固定仓库提交版本、下载、安装、启动并检查服务；缺少 Python 时按说明准备用户目录运行时。成功后直接在我的浏览器打开工作台，并保留以后可以再次打开的固定入口和供后续分析使用的固定项目工作目录。打开前检查 Python、数据库、HTTPS 和必要页面与字表资源，缺项由你自动修复后重新检查，不把命令交给我。黑岩入口是腾讯文档书单 https://docs.qq.com/sheet/DYVNwaVJZV2ZxTWl3?tab=q1ans7 ，点击后在我的普通浏览器登录，不需要另装 Node 或 Playwright。已经安装过就复用，更新时保留我的榜单、收藏、报告和登录状态。以后我在这个项目里说“分析刚选的这本”“分析长篇第二本”或“分析番茄新书榜第14名”，就读取真实工作台记录，定位作品、取得可用文本、由当前对话分析，再把报告保存回工作台；取不到正文时说明实际范围。请直接执行，不只给我操作步骤；需要我本人登录平台或遇到真正无法继续的问题时再告诉我，不要把远程环境中的 localhost 当成我的电脑。

安装过程由 [INSTALL.md](INSTALL.md) 规定。正常流程是：WorkBuddy 准备环境 → 下载指定 GitHub 版本 → 启动本机服务 → 检查服务与版本 → 浏览器打开白色工作台。安装器先验证本地运行依赖和必要资源，通过后才打开页面。当前黑岩书单使用普通浏览器，不触发专用浏览器安装。

**实测边界：** 上面是给 WorkBuddy 执行的完整安装指令，不代表已经在你的客户端安装。远程下载、Windows/macOS 安装、用户浏览器显示与 WorkBuddy 实际拆书分别验收；尚未实测的环节以 [验收记录](docs/acceptance.md) 为准，不宣称所有电脑和平台均已跑通。

关闭工作台网页或 WorkBuddy 对话不删除记录，也不会停止独立运行的本地程序。电脑重启后重新打开启动文件。

工作台不要求用户注册独立账号。公开 GitHub 仓库的下载也不要求用户登录 GitHub；黑岩等第三方平台的个人登录与访问资格仍由相应平台决定。

## 日常操作

服务与采集已自动隔离 WorkBuddy/IDE 的临时会话代理。需要固定代理或排查断连时，由维护助手按 [网络维护](docs/network.md) 操作。

- 打开工作台即显示已有榜单，当前条件过期后自动更新；切换平台或榜型也会自动读取。可随时手动更新；失败保留原来的结果。
- 默认最多读取 100 页，遇到来源结束、重复页或访问限制时提前停止，显示实际数量和停止原因。不会把 100 页上限当作已经取得 100 页。
- 作品列表展示来源封面、简介和实际指标；封面失效时显示书名占位。已选作品与历史记录不会因后台更新而悄悄换书，新数据准备好会提示查看。
- 首页后台同步 FanqieRankTracker 公开新书榜快照及可用的七日前记录，先补齐分类样本，再由直接采集持续补充。明确显示来源、真实日期与每分类样本范围，不将公开 Top 样本冒充全榜。公开源不可达时保留已有结果并继续直采，见 [公开数据来源](docs/public-data-sources.md)。
- 首页用数值和图表展示三家平台，保留各自榜型和指标；番茄可以切换全部、男频、女频，只包含新书榜。阅读榜仍可单独浏览，不进入汇总。
- 黑马筛选使用字数、当前在读和每万字在读；有同范围、不同来源日期的历史时，才计算实际增量和工具包的加权指数。筛选窗口、单位与公式可展开查看。书名句式仅作为次要分布统计，不再占据首页的大块公式卡。来源没有指标时不画零值图，具体口径见 `docs/v0.5-data-method.md`。
- 黑岩故事会入口打开用户指定的腾讯文档书单。在腾讯文档页面完成登录和访问授权；工作台不要求后台账号，也不接管文档登录状态。
- 点击一本书后，工作台保存选中对象。回到 WorkBuddy 可以说“分析刚选的这本”。“第二本”按当前筛选排序后的列表编号，“第 14 名”按原榜名次。
- 番茄作品可打开“目录与正文”，下载前几章、指定范围或明确选择全部已发布章节，再导出 TXT。正文自动关联原作品，回到 WorkBuddy 即可继续分析。
- “榜单观察”展示当前样本的标题关键词、句式、每万字在读和可比较的历史变化；没有历史时不显示虚构涨跌。这是规则统计，实际拆书仍由 WorkBuddy 阅读正文后执行。
- 文本导入只表示已取得用户提供的内容。是否完整、实际章节范围和来源都需要如实登记。
- 页面中的报告由对话分析后保存；本地服务没有偷偷接模型，也不会用固定模板冒充 AI 拆书。

平台实测边界见 [平台能力表](docs/platforms.md)，本次验证记录见 [验收记录](docs/acceptance.md)。首次打开没有真实数据时显示自动读取进度，不加载虚构书目。导入文件的准确格式见 [书目格式](docs/data-format.md)。产品设计参考与暂未实现的功能见 [设计依据](docs/design-reference.md)。

本版已融合用户提供的番茄工具包：直接解读榜单字段、公开章节读取、分类批量采集与本机跨榜检索。具体范围和真实验证见 [工具包融合记录](docs/toolkit-integration.md)。全分类采集与跨榜检索可由 WorkBuddy 调用，不要求用户自己操作命令行。

## 海外网文

侧栏点击“海外网文”即可展开海外平台，首次读取首批作品，向下浏览再取得后续页面；已有数据立即显示，并在后台检查更新。分类、榜型与指标名称为中文，作品书名、作者及简介保留来源英文。

| 平台 | 当前入口 | 默认条件 |
| --- | --- | --- |
| GoodNovel | 长篇分类榜 | 狼人，可切换言情、总裁等分类 |
| GoodNovel 短篇 | 热门短篇书库 | 全部，可切换言情等分类 |
| Dreame | 新书、上升、月票、畅销、完结、必读榜 | 新书榜 |
| MegaNovel | 长篇分类榜 | 奇幻，可切换都市、科幻、系统与游戏等 |
| Webnovel | 新书能量榜 | 男频，可切换女频；发表不超过 30 天的签约原创作品，周榜 |
| Royal Road | 新星榜 | 官网列表；读取失败时自动使用 RST 公开快照并标注来源日期 |
| Scribble Hub | 周收藏榜 | 官网读取；遇到访问拒绝时可打开官网或导入浏览器保存的榜单 HTML |

Royal Road 官网请求被拒绝或连接失败时，自动改用 RST 已保存的公开新星榜，显示实际快照时间、封面、英文书名、关注及浏览指标；RST 榜单接口未提供作者和简介。Scribble Hub 返回访问拒绝时暂停自动重试，保留已载入书目，并提供官网入口与“导入已打开的榜单”按钮；导入浏览器保存的周收藏榜 HTML 后即可选书。

选中一本后，直接回 WorkBuddy 说“翻译这本”，也可以点击“复制翻译请求”粘贴到对话。复制内容带固定快照与作品 ID，翻译由当前对话完成。原文和收藏照常保存在工作台。开发接口及实际覆盖见 [海外接入说明](docs/overseas.md)。

## 维护者启动方式

在本工程目录运行：

```sh
python3 scripts/launch.py
```

不自动打开浏览器（便于测试）：

```sh
python3 scripts/launch.py --no-browser --port 18376
```

前台运行并查看日志：

```sh
python3 -m fagao.server --port 18376
```

只绑定 `127.0.0.1`。默认端口为 `18376`；端口属于其他程序或另一份资料目录时，启动器会明确报错，不会打开错误程序。

## 资料位置、更新与备份

默认资料位置：

| 系统 | 默认目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\FagaoWorkbench` |
| macOS / Linux | `~/.fagao-workbench` |
| 自定义 | 环境变量 `FAGAO_DATA_DIR` 或启动器参数 `--data-dir` |

安装器将程序放在资料目录的 `app/releases/版本号`，通过 `app/current.json` 选择版本；数据库、正文与登录状态不放进版本目录。固定启动入口和 WorkBuddy 项目目录不随版本地址变化。更新请遵循 INSTALL.md，不手动覆盖正在运行的版本。备份前停止自己运行的本地服务，复制资料目录中的用户资料；浏览器会话不上传到公共仓库或共享压缩包。

启动日志在资料目录的 `logs/workbench.log`。启动后 `server.pid` 记录最近一次新启动进程的 PID；停止前核对进程身份，不能凭可能过期的 PID 盲目结束程序。

积分站正式取得域名后，由维护助手用 `python3 -m fagao config --points-site "实际的 HTTPS 地址"` 配置；网址为空时入口保持禁用。不要填临时假域名。

## 已知运行边界

Windows 与 macOS 启动入口已提供，Python 缺失时由 WorkBuddy 按 INSTALL.md 准备私有运行时。当前核心功能只需 Python 标准库；黑岩书单在系统浏览器中打开，不依赖 Node 或 Playwright。历史掌文后台适配仅为维护者保留，默认不作为黑岩入口。平台网络访问、腾讯文档账号权限和正文取得有各自的验证状态，详见平台能力表。GitHub 分发成功、工作台打开、平台数据可用与 WorkBuddy 实际拆书分别验收。
